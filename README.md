# beersbox-data

ที่เก็บไฟล์ของ [กล่องฝากไฟล์](https://titiwutnav-web.github.io/) ทุกไฟล์ในนี้ถูกเข้ารหัสแล้ว เปิดได้เฉพาะผู้ที่มีรหัส 8 ตัว

- `config.json` — GitHub token ที่ถูกล็อกด้วยรหัสผ่านสำหรับส่ง
- `d/` — ข้อมูลของแต่ละกล่อง (เข้ารหัส)
- `b/` — ชิ้นส่วนไฟล์ (เข้ารหัส)
- `.github/workflows/cleanup.yml` — ลบของที่หมดอายุทุก 3 ชั่วโมง และล้างประวัติเพื่อไม่ให้ repo โต

ถ้า token หมดอายุ: ลบ `config.json` แล้วเปิดหน้าเว็บ จะมีหน้าตั้งค่าครั้งแรกให้ใส่ token ใหม่
